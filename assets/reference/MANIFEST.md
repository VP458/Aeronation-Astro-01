## 5. Junk & dedupe rules (apply on every ingest)

1. **Resource forks:** every folder contains macOS `._*` files of exactly
   4096 bytes (confirmed). They are not images. `find . -name '._*' -delete`.
   Also delete `.DS_Store` (present in Drive too).
2. **Mirrored web assets:** the same composited web assets are mirrored across
   three or four parallel Drive folders (per the brief; PNG/JPG frame mirroring
   confirmed above). **Dedupe by filename + byte size, keep the first copy**,
   before treating any listing as an inventory. `scripts/ingest-assets.sh` does
   both steps automatically.
3. Frame-level duplication across formats (same frame as .jpg and .png) survives
   filename+size dedupe by design — key the catalogue on frame number instead.

## 6. IF THE SHOOT IS A SYSTEMATIC TURNTABLE — SAY IT LOUDLY

**This is the single most important thing the local visual pass determines.**

What the metadata says so far: frame numbering is sparse with gaps
(8862–8979 in the main folder; 8988–9050 in Additional/) — consistent with
hand-picked selects, NOT obviously a turntable. But the Additional/ discovery
means coverage is nearly double what the first listing suggested, and the dense
runs (9012–9050 at full res, several near-consecutive) could be angle sweeps.
Only eyeballs can settle it.

What to look for once the frames are on disk:

- **Constant elevation + regular azimuth steps** across a run of frames
  (e.g. every ~10–30° around the airframe at one camera height).
- Constant subject distance/framing and identical background/lighting within
  the run (a real turntable pass keeps the rig fixed and rotates the subject).
- Sort by frame number first — turntable passes are usually contiguous captures.

**If you find one, SAY SO LOUDLY in this file and to the team — it changes the
placeholder strategy entirely** (per the brief): instead of a synthetic
placeholder sequence, the Path B frame scrubber can be backed by the *real*
photography ordered into a pseudo-turntable (even a coarse 8–12-step rotation
beats a fake one). If no systematic sequence exists, the placeholder sequence
stays synthetic and must remain clearly marked as placeholder in the UI and
README until real turntable renders are produced.

## 7. How to close out this manifest (the 10-minute local task)

1. On a local machine with normal internet: `bash scripts/ingest-assets.sh`
   (add `--no-psd` to skip the 287 MB PSD). Everything lands under
   `assets/reference/drive/` (git-ignored).
2. Open `assets/reference/CATALOGUE-TODO.csv` (emitted by the script — one stub
   row per downloaded image) next to a thumbnail grid of the frames.
3. Fill azimuth ≈°, elevation ≈°, framing (full / detail / portrait), background
   per frame; copy the values into the tables above.
4. Decide: systematic turntable subset or not — update section 6 accordingly.
5. Optionally pull `1. Finals (1).zip` (690 MB) if the folder exports look
   lossy or incomplete.
